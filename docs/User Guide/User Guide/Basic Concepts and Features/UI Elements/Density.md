# Density
The **density** sets how much room the interface takes around your notes. Go to <a class="reference-link" href="Options.md">Options</a> → _Appearance_ → _User Interface_ and choose _Density_:

*   _Compact_ (the default) uses a shorter tab bar and tabs, a narrower <a class="reference-link" href="Launch%20Bar.md">Launch Bar</a> with smaller icons, tighter rows in the <a class="reference-link" href="Note%20Tree.md">Note Tree</a>, slightly smaller text and a shorter [note title](../Notes/Title.md), so the content starts higher on the page. The note tree also starts narrower, at a fifth of the window.
*   _Comfortable_ keeps the sizes of the theme.

The change applies at once and to the current device only.

> [!NOTE]
> If you set your own font sizes in _Appearance_ → _Fonts_, _Compact_ leaves them as they are.
> 
> A note tree you have resized keeps its width under either density.
